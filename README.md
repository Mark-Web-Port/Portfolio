# Mark John B. Torralba — Portfolio

A responsive, static personal portfolio website built with HTML, CSS, and vanilla JavaScript. It is ready to publish with GitHub Pages.

## Files

- `index.html` — portfolio content and page structure
- `style.css` — responsive visual design
- `script.js` — mobile navigation and automatic copyright year
- `assets/profile.jpg` — profile portrait

## Before publishing

Open `index.html` and replace these placeholders in the contact section:

- `YOUR_EMAIL@example.com`
- `https://www.linkedin.com/in/YOUR-LINKEDIN/`
- `https://github.com/YOUR-GITHUB-USERNAME`

Review the experience and project descriptions so they accurately reflect your current responsibilities and project status. The network plan and IT desk request system are labeled as planning/concept work rather than completed deployments.

## Preview locally

Open `index.html` in a browser. No build tools or dependencies are required. An optional local server can be started from this folder with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `mark-torralba-portfolio`.
2. Upload the contents of this folder (not just the ZIP file) to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site. The public URL will appear in the Pages settings.
